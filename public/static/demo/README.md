# Nora's pictures (devtag.io/demo)

Nora Lindqvist is made up (src/demo/config.ts), and so are these pictures. None shows a real person or product.

- `nora.jpg`: the illustration "Lorelei" by Lisa Wischofsky, drawn with [DiceBear](https://www.dicebear.com/styles/lorelei/)
  (seed `nora-lorelei-0`, blond hair, on Nora's theme colors). License: CC0 1.0, no attribution required. A JPEG because
  link previews read only JPEG and PNG.
- `floorplan-3d.webp`, `shelfie.webp`, `pg-snapshot.webp`, `tablemate.webp`, `commute-heatmap.webp`: screenshots of
  Nora's projects, made for the demo as HTML mock-ups rendered in Chrome (the 3D flat with three.js). 1600×1000, 16:10.
  The books in Shelfie are in the public domain and its barcode is the standard example ISBN; Tablemate's restaurants
  are fictional (two use Microsoft's sample names, like Nora's jobs); the map's travel times are invented.
